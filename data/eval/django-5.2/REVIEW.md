# Django benchmark author-review checklist

Status: **pending**. Do not call this benchmark frozen yet.

For every question, check:

1. The question has one clear meaning.
2. The reference answer says no more than its evidence supports.
3. The quoted evidence directly supports the answer, not merely a related fact.
4. The category is reasonable.
5. For an unanswerable item, the requested implementation detail is genuinely
   absent from all 12 selected files.

The exact-evidence validator has already completed the mechanical check. This
review is the semantic check that still requires human judgment.
